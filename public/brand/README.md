# Remnant Void — kit de marca

Arquivos extraídos e adaptados a partir do brandboard fornecido.

## Logos

- `logo-primary-{black|white}.{png|webp}` — logo principal horizontal com assinatura.
- `logo-vertical-{black|white}.{png|webp}` — logo alternativo vertical.
- `signature-horizontal-{black|white}.{png|webp}` — assinatura horizontal compacta.
- `signature-minimal-{black|white}.{png|webp}` — assinatura minimalista.
- `symbol-{black|white}.{png|webp}` — símbolo isolado em fundo transparente.

## Ícones e perfil

- `favicon-{16|32|64|180|512}.png` e `favicon.ico`.
- `app-icon-{light|dark}.{png|webp}` — 1024×1024.
- `avatar-{light|dark|texture}.{png|webp}` — 512×512.

## Aplicações

- `splash-{light|dark}.{png|webp}` — 1080×2400.
- `logo-on-{light|dark|texture}.{png|webp}` — amostras do brandboard.
- `brandboard.webp` — referência completa otimizada para web.
- `preview.jpg` — inventário visual rápido dos principais arquivos.

Use PNG quando precisar de transparência ou máxima compatibilidade. Use WebP no site para reduzir o peso do download.

## Atualização da identidade

- `icons/light-{16,32,64,180,192,512}.png`: símbolo preto original em fundo claro.
- `icons/dark-{16,32,64,180,192,512}.png`: versão invertida em fundo escuro.
- Favicon, Apple Touch Icon e manifesto usam essas versões; o favicon acompanha a preferência clara/escura do navegador.
- `hero-moon-hd.webp`: arte lunar recriada com ImageGen integrado, 1254 × 1254, transparência, destinada somente à ilustração principal.
